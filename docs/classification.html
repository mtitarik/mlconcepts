How the gradient and the parameter update are actually computed.

1. Loss function & partial derivatives

Binary cross-entropy. Unlike squared error, its gradient through the sigmoid cancels perfectly on its own — no extra ½ needed.

L = −(1/n) Σᵢ [yᵢ log p̂ᵢ + (1−yᵢ) log(1−p̂ᵢ)]
